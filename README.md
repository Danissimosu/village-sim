# Любимівка — симулятор села (v0.1)

Реалистичная 3D-сцена села **Любимівка** (Бучанський р-н, Київська обл.) на **Vite + Three.js (vanilla JS)**, рассчитанная на iPhone 16 Safari (WebGL2, сенсорное управление). Весь UI — на русском.

## Запуск
```bash
npm install
npm run dev          # разработка, http://localhost:5173
npm run build        # статическая сборка в dist/ (base './' — можно класть в любую папку/хостинг)
npm run preview      # vite preview, host 0.0.0.0, порт 5173
```
Параметры URL (для отладки): `?q=low|medium|high|ultra`, `?t=13.5` (час суток), `?day=0` (день недели, 0 = понедельник), `?auto=0` (остановить время), `?view=fp`, `?hud=0`.

## Управление
* Телефон: левая половина экрана — виртуальный джойстик (появляется под пальцем), правая — осмотр свайпом. Кнопки: качество, вид (3-е/1-е лицо), бег, скрыть меню, ползунок времени суток, пауза времени.
* ПК: WASD / стрелки, мышь (клик по сцене — захват курсора), Shift — бег, V — вид, R — бег вкл/выкл, Q — качество, T — пауза времени.

## Данные
* Центр: 50.43477 N, 30.06655 E (между S2-ячейкой Google ftid `0x472b49d65f7437c9` = 50.4351, 30.0621 и OSM place-node «Любимівка» 50.4344, 30.0710).
* OSM (Overpass, ODbL): здания, дороги, вода, лес/сады/поля, ограждения, ЛЭП, вышка → `tools/build_data.py` → `public/data/village.json`.
* Высоты: AWS Terrarium z14 (≈6 м/пкс) → `public/data/heights.bin` (281×281, шаг 5 м) + процедурный микро-рельеф. Пруды/ручей «вырезаются» в рельефе.
* В OSM у села только 8 зданий, поэтому дома, дворы, заборы, огороды, сараи, колодцы, деревья **генерируются** (`src/world/layout.js`, детерминированно) вдоль реальных дорог внутри реальных полигонов `landuse=residential`.
* Текстуры: Poly Haven CC0 (скачано 2K → 1K WebP; `tools/fetch_textures.mjs [размер]`), HDRI `kloofendal_48d_partly_cloudy_puresky` 1K (`tools/fetch_hdri.mjs`).

## Структура `src/`
* `world/data.js` — данные и поле высот · `layout.js` — генерация села · `splat.js` — растеризация (сплат-карта, коллизии, маски)
* `world/terrain.js` — рельеф + 5-слойный PBR-шейдер · `buildings.js`, `props.js`, `geo.js` — дома/заборы/столбы
* `world/vegetation.js` — деревья (InstancedMesh, 2 LOD, чанки) и трава/посевы (потоковые чанки) · `water.js` · `sky.js` (HDRI-купол, солнце/луна, туман, IBL)
* `player/player.js` — ходьба, коллизии, камера, джойстик · `ui/hud.js`, `style.css`


## Жители (NPC)
300 детерминированных (seed) жителей: имена/фамилии, пол, возраст (дети…старики), семьи по домам, профессии. Выбор жителя — тап/клик по нему (или `E` в прицел) → карточка: имя, возраст, занятие, что делает сейчас, адрес, размер семьи.
* `world/population.js` — **только данные** (без рендера): `generatePopulation(houses, opts) → Population {residents, households, stats()}`. Здесь будут расширяться игровые механики.
* `world/npc-nav.js` — граф пешеходных путей из дорог/троп OSM (A*, «выпрямление» маршрута, смещение к краю дороги), «места» (двери домов, огороды, магазины, остановки, пруды, сады/поля), адреса (улица + номер), 4 магазина и школа среди домов.
* `world/npc-schedule.js` — расписание на день по профессии/возрасту/дню недели (сон, огород, поле, магазин, пруд, гости, школа, работа в Киеве; выходные).
* `world/npc-sim.js` — конечный автомат, движение по маршрутам с привязкой к рельефу, обновление ближних каждый кадр, дальних — реже (10–2 Гц), спящих/в доме — раз в 0.6 с.
* `world/npc-render.js` — два `InstancedMesh` (ближний LOD ~570△ с анимацией конечностей в вершинном шейдере и тенью, дальний ~300△ статичный), отсев по дистанции и пирамиде видимости; параметры качества в `config.js` (`npcDist/npcNear/npcMaxNear/npcMax/npcFrac`).
* Игровые сутки теперь идут медленнее (60 мин реального времени, `TIME_SPEED` в `config.js`), чтобы жители успевали ходить пешком по расписанию.

## Hero-участки
* `?poi=35b` / кнопка «📍 Перейти к 35Б» — `src/world/hero.js` (общий каркас участка `makePlotFrame`: планировка рельефа, снос процедурных построек).
* `?poi=84` / кнопка «📍 Перейти к 84» — `src/world/hero84.js` (Польова, 84: белый двухэтажный дом, терракотовые ворота между каменными столбами, забор из тёмных горизонтальных досок, столб ЛЭП, подъезд, постройки).
* Закрытые ворота (`layout.gates`) блокируют игрока (`rasters.pblock`), а для жителей проход в воротах открыт.
